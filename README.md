# Apple WatchOS Compatibility Matrix

A condensed timeline reference of all Apple Watch models and their supported watchOS versions.

## Legend

| Symbol | Status | Description |
| :---: | :--- | :--- |
| 🟢 | **Launch** | Initial watchOS version pre-installed at release |
| 🟩 | **Supported** | Intermediate OS updates with full support |
| 🛑 | **Final** | Final supported major watchOS release |
| ⬛ | **Unsupported** | Not supported (pre-release or post-EOL) |

## Major EOL Milestones

* **watchOS 4.3.2**: Final release for 1st Gen (Series 0).
* **watchOS 6.3**: Final release for Series 1 & Series 2.
* **watchOS 8.8.1**: Final release for Series 3.
* **watchOS 10.6.1**: Final release for 32-bit architecture models (Series 4, Series 5, SE 1st Gen).
